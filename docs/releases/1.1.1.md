# IndexLane 1.1.1

This maintenance release fixes the suggested-fix batch introduced in 1.1.0.

- Classic menu custom links now take part in batch repairs and Undo.
- Each original stored link is replaced once. When one suggestion's destination is another suggestion's original URL, the reviewed replacements remain independent and occurrence counts stay accurate.
- Uneditable suggestions no longer block confirmation of valid changes in the same preview. Selected URL pairs and original stored values remain protected by confirmation.
- The suggested-fix summary counts distinct sources and describes where suggestions were found, without promising that every source can be edited.
- Trailing-slash checks preserve case-sensitive query-string differences.
- The documented `wp indexlane fix-suggested` command is now registered with its hyphenated name. JSON and CSV output no longer include human-readable status messages.
- Integration and AJAX checks now read the release version from the plugin header instead of expecting 1.0.0.

The 1.1.0 release and its notes are preserved. This release adds no new settings or storage format.
